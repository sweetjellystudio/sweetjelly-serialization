#   Serialization compatibility fixtures

legacy.json, legacy.xml and legacy-aes.txt were generated by the unchanged 1.0 source (repository baseline f3f585a) on Unity 6000.3.27f1 before the 2.0 implementation. The DTO is SerializationTestData with Id=73 and Name="Legacy 한글". The encrypted fixture uses the synthetic key `legacy-fixture-key`; it is public test data, not an application secret. Keep the old ciphertext fixed instead of regenerating it with the current writer.

authenticated-v1.txt was generated independently with Python hashlib/HMAC plus Git's OpenSSL AES-256-CBC implementation: key above, salt bytes 0 through 15, IV bytes 16 through 31, PBKDF2-HMAC-SHA512/220,000, and JSON bytes matching legacy.json. Its deterministic salt/IV exist only to define a stable cross-implementation test vector; production writes use cryptographic randomness.
